# Système de gestion de magasin

Projet académique de gestion de magasin développé en Python (Tkinter) 
avec une base de données PostgreSQL.

## Fonctionnalités
- Gestion des produits et catégories
- Gestion des ventes et reçus
- Gestion des commandes d'achat
- Suivi des stocks
- Statistiques via vues SQL

## Technologies
- Python (Tkinter)
- PostgreSQL
- pgAdmin
- Git / GitHub

⚠️ Configuration de la base de données

Copier :
db/db_config_example.py → db/db_config.py

Puis modifier les identifiants PostgreSQL.
